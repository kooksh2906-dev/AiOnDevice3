01 · OVERVIEWEDGESCOPE-LITE REGISTER DESCRIPTION

1. 개요

EdgeScope-Lite는 8개 디지털 채널을 병렬로 Sampling하고, Rising/Falling/Masked Pattern 조건을 하드웨어에서 검출한 뒤 Trigger 전 512개와 Trigger를 포함한 이후 512개 Sample을 Capture BRAM에 보존하는 독립형 Logic Analyzer이다. MicroBlaze V는 각 IP의 AXI4-Lite CSR을 설정하고 Capture 완료 후 BRAM 데이터를 읽는다.

8 CHParallel Digital Input
100 MS/sMaximum Sample Rate
1,024512 Pre + 512 Post

1.2 주소 계산 및 접근 기호

주소 계산

Actual Address = IP Base Address + Register Offset

예: Trigger STATUS = 0x4002_0000 + 0x0C = 0x4002_000C

접근 기호

R Read · RW Read/Write · W1P 1을 기록하면 1-Clock Pulse 발생 · RO=0 읽으면 0

주소 사용 규칙: 아래 Base Address는 최종 Reference Design 전용이다. 다른 Vivado 설계에서는 BSP의 xparameters.h를 사용해야 한다. Custom IP는 하위 6-bit Local Address를 Decode하므로 문서에 정의된 Offset 외의 주소에는 접근하지 않는다.

2.2 CONTROL — Sampler Control Register

Bit31:210
FieldReservedSOFT_CLEARENABLE
Access—W1P / R=0RW
Reset000
  • ENABLE[0]: 1이면 Sampling을 수행한다. 0이면 sample_valid_o를 중지하고 Divider Phase를 0으로 재설정한다.
  • SOFT_CLEAR[1]: 1을 기록하면 Sample Data, Sample Count와 Divider Phase를 초기화하는 1-Clock Pulse가 발생한다.
  • ENABLE=0만 기록해도 LAST_SAMPLE과 SAMPLE_COUNT는 유지된다.

0x0000_0001Sampling Enable
0x0000_0002Soft Clear 후 Disable 상태
0x0000_0003Soft Clear 후 Enable 유지
Runtime: Divider 변경 시 Phase가 0에서 재시작되며 그 Cycle에는 sample_valid_o가 발생하지 않는다. 권장 설정 순서는 ENABLE=0 → CONFIG → CONTROL=0x3이다.

3. Basic Trigger Engine IP

유효 Sample Stream에서 Rising, Falling 또는 Masked Pattern Entry를 검출한다. 검출된 Sample과 같은 Cycle에 1-Clock trigger_pulse_o를 생성하며, 한 번 ARM할 때 최대 한 번만 Trigger된다.

3.2 CONTROL — Trigger Command Register

Bit31:210
FieldReservedCLEARARM
Access—W1P / R=0W1P / R=0
Reset000
  • ARM[0]: ARMED를 Set하고 TRIGGERED와 Sample/Pattern History를 초기화한다.
  • CLEAR[1]: ARMED, TRIGGERED와 History를 초기화한다.
  • ARM과 CLEAR는 TRIGGER_COUNT를 초기화하지 않는다.
  • 동시 기록 우선순위는 Hardware Reset > CLEAR > ARM > Normal Processing이다.
  • CONTROL은 WSTRB[0]=1일 때만 동작하며 읽으면 항상 0이다.

3.4 PATTERN — Masked Pattern Register

Bit31:1615:87:0
FieldReservedPATTERN_MASKPATTERN_VALUE
Access—RWRW
Reset00xF00xA0
 
current_match =
    (sample_data & PATTERN_MASK) == (PATTERN_VALUE & PATTERN_MASK)
  • PATTERN_MASK bit=1인 채널만 비교하고, bit=0인 채널은 Don't Care이다.
  • PATTERN_MASK=0x00이면 Pattern Trigger는 명시적으로 Disable된다.
  • ARM 후 첫 유효 Sample이 Pattern과 일치하면 즉시 Trigger될 수 있다.
  • 한 번 Trigger된 뒤에는 Pattern이 다시 진입해도 CLEAR 또는 새 ARM 전까지 재Trigger하지 않는다.
  • PATTERN_VALUE는 WSTRB[0], PATTERN_MASK는 WSTRB[1]에서 갱신된다.
같은 Sample 정렬: trigger_pulse_o는 조건을 만족한 유효 Sample과 같은 Cycle에 발생한다. Capture Buffer는 그 Sample을 Logical Index 512에 보존한다.

ARMED[0]

Bit31:0
FieldTRIGGER_COUNT

4. Circular Trace Buffer IP

Sample Stream을 1,024 × 32-bit True Dual-Port BRAM의 Port A에 Circular Write하고, Trigger 전 512개와 Trigger Sample을 포함한 이후 512개를 보존한다. 완료 상태는 DONE과 Level IRQ로 유지된다.

4.2 CONTROL — Buffer Command Register

Bit31:3210
FieldReservedABORTCLEAR_DONEARM
Access—W1PW1PW1P

  • ARM[0]: IDLE 또는 DONE에서 Capture를 PREFILL 상태로 시작한다.
  • CLEAR_DONE[1]: DONE에서 DONE/TRIGGERED/IRQ를 지우고 IDLE로 돌아간다. BRAM과 주소값은 지우지 않는다.
  • ABORT[2]: 모든 상태에서 Capture와 상태/주소 Counter를 즉시 초기화한다. BRAM Data 자체는 지우지 않는다.
  • CONTROL은 WSTRB[0]=1일 때만 동작하며 읽으면 0이다.
상태 의존 우선순위: ABORT는 모든 상태에서 최우선이다. CLEAR_DONE은 DONE에서만 유효하며 이때 ARM보다 우선한다. ARM은 IDLE/DONE에서만 유효하고, BUSY 중 ARM과 CLEAR_DONE은 모두 무시된다.

4.7 Trigger Sample Contract

  • PREFILL에서 Trigger 입력은 무시하며, 512번째 PREFILL Sample도 Pre Sample로만 처리한다.
  • ARMED 상태에서 Trigger와 정렬된 유효 Sample을 Post Sample #1로 저장한다.
  • 이후 511개를 추가 기록하여 총 Post 512개가 되면 DONE으로 전환한다.

4.8 Capture BRAM Mapping

Port A — Hardware Write

Circular Trace Buffer가 유효 Sample마다 32-bit Word 전체를 기록한다.

capture_word = {24'h0, sample_data[7:0]}

Port B — MicroBlaze Access

AXI BRAM Controller를 통해 CPU가 Capture Data를 읽는다.

byte_addr = 0x4200_0000 + word_index × 4

Software Contract: Capture Data는 STATUS.DONE=1을 확인한 후 읽는다. Port B Write와 BUSY 중 Read는 하드웨어가 차단하지 않지만 Reference Software에서는 사용하지 않는다. 따라서 Word[31:8]=0이라는 설명은 Trace Buffer가 Port A로 기록한 Word에 한해 성립한다.
Logical Read: Logical Index i의 Physical Word는 (START_ADDR + i) & 0x3FF이며, BRAM Byte Address는 0x4200_0000 + (physical << 2)이다.

5.2 권장 Capture 순서

  1. Trigger CLEAR 및 Buffer ABORT로 이전 상태를 정리한다.
  2. Sampler CONFIG, Trigger CONFIG/PATTERN을 기록한다.
  3. Buffer ARM 후 Sampler를 SOFT_CLEAR + ENABLE한다.
  4. Buffer PRE_READY=1을 확인한 뒤 Trigger를 CLEAR하고 ARM한다.
  5. Buffer DONE=1 또는 Trace IRQ를 기다린다.
  6. START_ADDR를 기준으로 Capture BRAM의 1,024 Word를 Logical 순서로 읽는다.
Trigger Engine을 PRE_READY 전에 ARM하면 PREFILL 중 One-Shot Trigger가 먼저 소진될 수 있다. Trigger 설정은 미리 기록하되 실제 ARM은 PRE_READY 확인 후 수행한다.

5.3 Integrated Software Example

/* Buffer arm, sampler clear+enable */
Xil_Out32(TRACE_BASE   + TRACE_REG_CONTROL, TRACE_CONTROL_ARM);
Xil_Out32(SAMPLER_BASE + SAMPLER_REG_CONTROL,
          SAMPLER_CONTROL_ENABLE | SAMPLER_CONTROL_SOFT_CLEAR);

while ((Xil_In32(TRACE_BASE + TRACE_REG_STATUS)
        & TRACE_STATUS_PRE_READY) == 0U) { }

Xil_Out32(TRIGGER_BASE + TRIGGER_REG_CONTROL, TRIGGER_CONTROL_CLEAR);
Xil_Out32(TRIGGER_BASE + TRIGGER_REG_CONTROL, TRIGGER_CONTROL_ARM);

while ((Xil_In32(TRACE_BASE + TRACE_REG_STATUS)
        & TRACE_STATUS_DONE) == 0U) { }

u32 start = Xil_In32(TRACE_BASE + TRACE_REG_START_ADDR) & 0x3FFU;
for (u32 i = 0; i < 1024U; ++i) {
    u32 physical = (start + i) & 0x3FFU;
    u8 sample = Xil_In32(BRAM_BASE + (physical << 2)) & 0xFFU;
}
