# CAN_BUS 펌웨어의 주행 코드 구성

차량 구동부의 FreeRTOS 태스크 및 모터 명령 큐는 `Core/Src/freertos.c`의
`MX_FREERTOS_Init()`에서 생성합니다.

| 코드 | 책임 |
| --- | --- |
| `freertos.c`, `motor_task.h` | 태스크 생성, 모터 명령 큐, 수동·자율 모드 중재, 정지 요청, 모터 상태 공유 |
| `bluetooth_control.c` | UART 인터럽트 수신 및 수동 명령 전달 |
| `manual_drive.c/.h` | 수동 주행의 방향·가속 버튼·PWM 증감 상태 계산 |
| `autonomous_drive.c` | 초음파 측정 및 장애물 회피 동작 결정 |
| `motor_control.c/.h` | GPIO 방향 핀과 PWM을 통한 모터 출력 |

일반 수동 명령과 자율 주행 동작은 Motor 태스크의 큐로 전달됩니다. 모터 출력은
Motor 태스크만 변경합니다. 이 프로젝트에 포함된 CMSIS-FreeRTOS 구현은
`osMessageQueuePut()`의 메시지 우선순위 인자를 무시합니다. 따라서 `S`와 `r`
즉시 정지는 큐와 별도의 요청 플래그로 전달하며, Motor 태스크가 대기 중인
주행 명령을 비우고 정지시킵니다. 자율 모드에 진입할 때도 먼저 정지한 다음
자율 주행 태스크가 새 센서 측정을 마쳐 동작을 결정하도록 했습니다.

`q`는 기존 수동 감속 명령으로 유지했습니다. 기존 설정은 PWM을 2초마다 50씩
줄이므로 최대 PWM 1000에서 정지까지 계산상 약 40초가 걸립니다. 즉시 정지가
필요하면 `S` 또는 `r`을 사용합니다. 감속 시간은 실제 RC카 하드웨어에서
확인한 뒤 조정해야 합니다.

새로 추가된 `Core/Src/manual_drive.c`를 STM32CubeIDE 프로젝트에 등록해야
빌드할 수 있습니다. 이 보관용 저장소에는 `.ioc`, 링커 파일 및 IDE 프로젝트
설정이 들어 있지 않습니다.
